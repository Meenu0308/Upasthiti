# MediWiki Assistant

add a feature called MediWiki  — a smart medicine information assistant that works like a Wikipedia for medicines.
Build the first version on Lovable’s full-stack architecture, starting with the DDHS attendance dashboard and role-based access.Users can:

Search medicine by name

Upload / scan photo of tablet, package, syrup bottle, injection

Instantly identify medicine

View clean expandable medicine profile

Save medicines

Compare medicines

Track recent searches
